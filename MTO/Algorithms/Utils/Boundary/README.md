# Boundary handling utilities

These functions centralize the boundary strategies already used by MToP
algorithms. They operate on normalized decision variables in `[0, 1]` and
convert decisions to real values before applying the original repair rule.

| Function | Existing strategy preserved |
| --- | --- |
| `BoundaryClip` | Clamp to `[0, 1]` |
| `BoundaryMidpoint` | Move a violation halfway toward its parent |
| `BoundaryRandomReset` | Replace a violation with caller-supplied random values |
| `BoundaryRandomResample` | Resample only violated dimensions |
| `BoundaryRandomParent` | Sample between the parent and violated bound using full arrays |
| `BoundaryRandomParentScalar` | Scalar form of parent-to-bound sampling |
| `BoundaryReflectRandom` | Existing random reflection-or-endpoint policy |
| `BoundaryViolation` | Squared distance outside an interval |

The optional final `Prob` argument skips repair when `Prob.Bounded` is false,
while still returning real decisions. Calls that omit `Prob` remain
unconditional so the behavior of existing algorithms is unchanged.

Randomized helpers deliberately preserve the random-number consumption and
ordering of the code they replace. In particular, `BoundaryRandomReset`
accepts values generated by its caller, and `BoundaryRandomParent` keeps its
two full-size random draws.

Run `tests/test_boundary_utils.m` in MATLAB R2022b or later to compare each
strategy and its resulting RNG state with the corresponding legacy logic.
